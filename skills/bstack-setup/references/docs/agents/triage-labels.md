# Triage labels

Use Matt Pocock's canonical triage labels in local `work-docs/` records.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Waiting for owner evaluation. |
| `needs-info` | Missing required context or facts. |
| `ready-for-agent` | Scoped for agent work once its stage and blockers are cleared. |
| `ready-for-human` | Requires human implementation. |
| `wontfix` | Will not be implemented; retain the reason. |
